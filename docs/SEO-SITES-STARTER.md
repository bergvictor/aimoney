# Zero-spend starter: SERP census (draft, queued for the owner)

Seed row: `ai-seo-content-sites` — "Programmatic SEO niche sites"
(`d1/seed.sql`, status `backlog`). The seed row lists a paid-tool starting
range; this starter needs none of it. This draft only describes the
experiment; the owner presses Vet / Vet-&-starter, Start, and Win/Lose
(`docs/OWNER-ACTIONS.md` §3). No spend, no new account, no domain bought,
no page published, no message, post, or accepted term is needed before the
week-1 number exists.

## Hypothesis

At least one of 10 reviewed programmatic niches shows two or more independent
traffic-monetization signals visible on public pages alone (a ranking page
with visible affiliate links or display ads, a keyword whose top results
include two or more thin programmatic pages, a niche with a public traffic
estimate attached to a monetized page). Falsified if zero niches pass.

## Metric and the single week-1 number

Metric: passing niches (0–10) — niches passing the two-signal bar, counted
0–10. The week-1 number is that one integer (for example `1/10 niches pass`).
It is a count, not dollars:
expected revenue stays unknown — no revenue figure is named anywhere in this
starter because none has evidence behind it yet.

## $0 cost breakdown

- Tools: $0 (browser + local files already owned; no new subscription).
- Data: $0 (public search results and ranking pages; no paid report).
- Outreach: $0 (none sent — this starter reads only).
- Total spend: $0. Owner time is the only input (about one focused evening).

## First steps

1. List 10 candidate niches from the row's brief (one line each, with the
   search that finds its ranking pages).
2. Fix the traffic-signal rubric before reading: what counts as one signal,
   what does not (a tool vendor's traffic estimate alone never counts).
3. Review the 10 niches oldest-first, recording at most 3 signal links per
   niche plus its pass/fail — about 15 minutes per niche.
4. Tally the single number: how many of the 10 pass the two-signal bar.
5. Decide by the number: 1+ passing niches → the next starter outlines the
   winning niche's smallest test section; 0 passing → close this experiment
   `lost` with the tally as the result and a one-line post-mortem, and Kill or
   re-scope the row's programmatic angle the same day.

## Logging it

Press `Vet & log starter` on the seed row, name the experiment
"SERP census: 10 programmatic niches", paste the hypothesis above into the
hypothesis field, "passing niches (0–10)" into the metric field, and
"1+ passing niches" into the target field, then Start
it. Close with Win/Lose only with the tally plus post-mortem in hand — never
enter a $ figure without a receipt behind it.
