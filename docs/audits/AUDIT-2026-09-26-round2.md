## 1. What this project is and how it runs

- Purpose: AIMoney Lab — a ranked ledger of AI-money opportunities with research briefs, experiments, and a cron research agent that proposes/refreshes rows; the human vets, tests, kills/scales.
- Entry points: `public/index.html` + `public/app.js` (dashboard); `functions/api/[[path]].js` (REST API on D1); `worker/src/index.js` (research agent: cron + `POST /run` + `GET /`).
- Live surfaces: `https://aimoney.pages.dev`, `https://aimoney.pages.dev/api/health`, worker `https://aimoney-research.levitinvlad.workers.dev/` (see `deploy/public-surfaces.json:38`).
- Scheduled jobs: worker cron `0 */6 * * *` (`worker/wrangler.toml:9`); each tick collects signals, triages ≤6 (supports/noise even while paused, round 1), inserts ≤2 proposals (0 while paused), briefs 1–2 bare rows.
- Deploy: Pages Git-connected (`public/`, stamped by `scripts/stamp-release.sh`); worker + D1 migrations via `deploy/deploy.sh` or `.github/workflows/deploy-worker.yml`; gated by `deploy/verify.sh` (revision + worker-status gates).

## 2. End-to-end walk-through

Main flow — signal → proposal → vetting → experiment → decision (the lane-metric path):

1. Cron tick opens a run row (`worker/src/index.js:361-370`, reaper `:355-360`) and collects HN/Reddit/GitHub signals in parallel (`:386`; collectors `:49`/`:81`/`:110` with body-covering timeout `:37-47`), inserting them in one batch (`:397-402`).
2. Unprocessed signals older than 30d are swept to noise (`:413-418`); the 6 oldest unprocessed are taken (`:420-422`); exact-URL duplicates pre-link as supports with no AI call (`:434-461`, pure `exactUrlTarget` `:174-184`).

Inflow gates read bare-without-brief and unreviewed counts (`:476-483`); while unreviewed > 10, inserts cap to 0 but the tick still runs the one classify call and applies only supports/noise verdicts (`:494-505`, `buildClassifyPrompt` `:315-327`, NDJSON `parseJsonLines` `worker/src/lib.js:64-79`), logging `inflow:paused` — round-1 change, not yet live (F3).

## 5. What NOT to change

- Default-off migration gate — deliberate: "Default-off: unset changes nothing; the health payload then names the missing columns plus the disabled line." (`functions/api/[[path]].js:23-24`; `README.md:83`; `docs/OWNER-ACTIONS.md` §2). F1's write tolerance must not flip or bypass it; the owner sets the var.
- Agent proposes, human disposes — deliberate: "The agent PROPOSES; the human owns the testing workflow (it never moves status to testing/scaling/killed)." (`worker/src/index.js:4-5`; `README.md:72` "The agent never moves status"). No auto-transitions, no bulk verdicts ("one human verdict per keypress, no bulk path", `README.md:71`). Pinned by `worker/src/index.test.js:2436` ("worker source records no vetted verdict and clears no UNREVIEWED marker").
- Manual `Run triage now` skips briefs — deliberate: "The manual path shares waitUntil's 30s cap (proven live), so it runs collect+classify only" (`worker/src/index.js:381-384`); briefs land on cron ticks.
- Killed rows stay listed with their post-mortem ("Killed strategies stay on the board with their post-mortem — that is the point.", `README.md:64`); closes require result + post-mortem; outcome ledger never touches the score and rescore is "never auto-applied" (`README.md:74`).
- Received-only revenue semantics ("only money actually received goes here, since every recorded cent counts toward lifetime revenue", `README.md:74`); "never enter a $ figure without evidence" (`docs/OWNER-ACTIONS.md:57`). Never invent `$` figures, reviews, or testimonials.
- Stamped files: `public/release.json` reads `{"revision":"dev-undeployed",…}` in the repo — stamped at build by `scripts/stamp-release.sh`; `worker/src/rev.js` "rewrites this file on every deploy; the committed \"unknown\" is the wrangler-dev default." Do not hand-edit either.
- Owner-only one-liners (needs a login, credential, deploy, or human decision — not implementer tasks): set `ALLOW_SCHEMA_MIGRATION=1` on the Pages project and retry the deployment (F1's real unblock for $ tracking); add `CF_API_TOKEN`/`CF_ACCOUNT_ID` repo secrets and redeploy (or run `deploy/deploy.sh`) for the `revenue_source` column (F6); clear Needs-review with `V`/`K` (F2); deploy HEAD + run `deploy/verify.sh` so round-1 ships (F3); press `Vet & log starter` → `Start` → `Win`/`Lose` on a $0 starter within a week. Never spend money, create accounts, sign up, accept terms, send outbound messages, or enter credentials from a task.
