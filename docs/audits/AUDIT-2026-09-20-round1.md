# AUDIT-2026-09-20-round1 — aimoney (read-only)

## 1. What this project is and how it runs

- Purpose: AIMoney Lab — a ranked list of AI-money opportunities with research briefs, money-tracked experiments, and a cron research agent that proposes new rows; the owner vets, tests, then kills/scales.
- Entry points: dashboard `public/app.js` + `public/index.html`; API `functions/api/[[path]].js` (D1); agent `worker/src/index.js` with shared pure helpers in `worker/src/lib.js`.
- Live surfaces: `https://aimoney.pages.dev/` (dashboard), `/api/health`, `/api/opportunities`, `/api/runs`, `/release.json`; worker `https://aimoney-research.levitinvlad.workers.dev/` (see `deploy/public-surfaces.json`).
- Scheduled jobs: worker cron `0 */6 * * *` (`worker/wrangler.toml:8-9`) — collect signals, AI-triage (6/run), brief 1+1 bare rows, log to `agent_runs`; manual `POST /run` is triage-only (`worker/src/index.js:640`).
- How it deploys: `deploy/deploy.sh` (D1 schema + shared migrations + seed guard, stamp `release.json`, Pages + worker) or Git push (Pages auto-build via `scripts/stamp-release.sh`; worker via `.github/workflows/deploy-worker.yml`); `deploy/verify.sh` gates the rollout on the live revision.

## 2. End-to-end walk-through

Main flow: public signal → agent proposal → human vet → experiment → decided (won/lost with post-mortem and money).

1. Cron fires `scheduled` → `runResearch(env, "cron")` (`worker/src/index.js:566-569`, `:218`). Stuck `running` rows older than 30 min are reaped (`:222-227`); a new `agent_runs` row opens (`:228-237`).

4. Exact-URL pre-pass (`:292-318`) links taken signals to an existing `source_url` via pure `exactUrlTarget` (`:167-177`) — no AI call, notes newest-kept, no status move.
5. Classify: one Workers AI call (`AI_CLASSIFY`, `:329-350`) with the top-60 list + fresh signals; NDJSON parsed by `parseJsonLines` (`worker/src/lib.js:62-77`, `repairJson` `:60` unescapes `\_`). Quiet ticks skip the fetch, prompt, and call (`:329`); manual runs share the same skip.
6. Verdicts validate (first-wins index, strict enum, numeric-or-null id), inflow caps at `MAX_NEW_PER_RUN = 2`, dropping to 1 while bare-without-brief exceeds 10 (`:353-369`). `new` inserts a `researching` row with `UNREVIEWED` + score capped ≤6000 via shared `effectiveScore` (`worker/src/lib.js:29-32`) + reversible money estimates (`agentMoneyEstimates`, `:179-194`); slug collision links as supports (`worker/src/index.js:413-425`); verdict writes flush as one batch with per-write fallback (`flushVerdictWrites`, `:196-217`, called `:439`, `verdict:N_failed` marker `:558`).

10. Experiment loop: `openExperimentModal` (`public/app.js:1053`) POSTs `/api/experiments` (`functions/api/[[path]].js:324-373`, parent 404 `:333-334`, closure gate `:335-340`, stamps `:344-345`, ledger append on close `:362-371`); board `renderExperiments` (`public/app.js:655`) sorts stale-first with `Nd` chips from `days_in_status` (`functions/api/[[path]].js:302-322`, `daysSince` `:287-292`, `statusRefOf` `:297-300`); `Start` (`public/app.js:597`) PATCHes `running` (API stamps `started_at`, `:397`); `Win` (`:652` via `inlineWinClose` `:338`) / `Lose` PATCH `won`/`lost` with result + post-mortem (API gate `:398-403`, `ended_at` stamp `:403`, outcome-ledger append with `$X rev / $Y spent [via source]` to parent notes `:408-417`).
