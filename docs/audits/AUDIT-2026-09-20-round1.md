## 1. What this project is and how it runs

- Purpose: ranked list of AI-money opportunities with research briefs, experiments, and a cron research agent that proposes new rows; the human vets, tests, kills/scales (`README.md:3-16`).
- Entry points: `public/index.html` + `public/app.js` (dashboard); `functions/api/[[path]].js` (REST API on D1); `worker/src/index.js` (research agent: cron + `POST /run`).
- Live surfaces: `https://aimoney.pages.dev/` (dashboard), `/api/health`, `/api/opportunities`, `/api/runs`, `/release.json`; worker `https://aimoney-research.levitinvlad.workers.dev/` (`deploy/public-surfaces.json:32-45`).
- Scheduled jobs: worker cron `0 */6 * * *` (`worker/wrangler.toml:9`); each tick collects signals, triages (≤6), briefs (1+1 on cron; manual `POST /run` is triage-only).
- How it deploys: `deploy/deploy.sh` (D1 schema + shared migrations + seed guard, stamp `release.json`, Pages + worker) or Git push (Pages auto-build via `scripts/stamp-release.sh`; worker via `.github/workflows/deploy-worker.yml`); `deploy/verify.sh` gates the rollout on the live revision.
