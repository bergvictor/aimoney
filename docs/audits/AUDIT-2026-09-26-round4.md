## 1. What this project is and how it runs

- Purpose: AIMoney Lab — a ranked ledger of AI-money opportunities with research briefs, experiments, and a cron research agent that proposes/refreshes rows; the human vets, tests, kills/scales.
- Entry points: `public/index.html` + `public/app.js` (dashboard); `functions/api/[[path]].js` (REST API on D1); `worker/src/index.js` (research agent: cron + `POST /run` + `GET /`).
- Live surfaces: `https://aimoney.pages.dev`, `https://aimoney.pages.dev/api/health`, worker `https://aimoney-research.levitinvlad.workers.dev/` (see `deploy/public-surfaces.json:38`; worker root was not fetched this round).
- Scheduled jobs: worker cron `0 */6 * * *` (`worker/wrangler.toml:9`); each tick collects signals, triages ≤6 (supports/noise even while paused), inserts ≤2 proposals (0 while paused), briefs 1–2 bare rows.
- Deploy: Pages Git-connected (`public/`, stamped by `scripts/stamp-release.sh`); worker + D1 migrations via `deploy/deploy.sh` or `.github/workflows/deploy-worker.yml`; gated by `deploy/verify.sh` (revision + worker-status + freshness gates).

Never invent `$` figures, reviews, or testimonials. Unknown money stays null, never $0 (`README.md:83`).
