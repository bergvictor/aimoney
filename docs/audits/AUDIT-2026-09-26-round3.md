## 1. What this project is and how it runs

- Purpose: AIMoney Lab — a ranked ledger of AI-money opportunities with research briefs, experiments, and a cron research agent that proposes/refreshes rows; the human vets, tests, kills/scales.
- Entry points: `public/index.html` + `public/app.js` (dashboard); `functions/api/[[path]].js` (REST API on D1); `worker/src/index.js` (research agent: cron + `POST /run` + `GET /`).
- Live surfaces: `https://aimoney.pages.dev`, `https://aimoney.pages.dev/api/health`, worker `https://aimoney-research.levitinvlad.workers.dev/` (see `deploy/public-surfaces.json:38`; worker root was not fetched this round).
- Scheduled jobs: worker cron `0 */6 * * *` (`worker/wrangler.toml:9`); each tick collects signals, triages ≤6 (supports/noise even while paused, round 1), inserts ≤2 proposals (0 while paused), briefs 1–2 bare rows.
- Deploy: Pages Git-connected (`public/`, stamped by `scripts/stamp-release.sh`); worker + D1 migrations via `deploy/deploy.sh` or `.github/workflows/deploy-worker.yml`; gated by `deploy/verify.sh` (revision + worker-status gates).

## 2. End-to-end walk-through

Main flow — signal → proposal → vetting → experiment → decision (the lane-metric path):

2. Unprocessed signals older than 30d are swept to noise (`:414-415`); the 6 oldest unprocessed are taken (`:420-422`); exact-URL duplicates pre-link as supports with no AI call (`:431-460`, gates `:476-483`).
3. Inflow gates read bare-without-brief and unreviewed counts (`:476-483`); while unreviewed > 10, inserts cap to 0 but the tick still runs the one classify call and applies only supports/noise verdicts (`:498`, `buildClassifyPrompt` `:315`, NDJSON `parseJsonLines` `worker/src/lib.js:64-79`), logging `inflow:paused` — round-1 change, not yet live (F1).

5. Cron ticks brief 1 bare row (top-scored, or oldest-unreviewed-first past 48h) plus 1 extra oldest-unreviewed past 48h (`:609-715`); manual `POST /run` always skips briefs (`:381-384`, `:801-804` returns 202 + `briefs_skipped:true`).
