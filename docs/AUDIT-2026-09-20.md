## 2. Money path

Intended: priority list → brief → experiment (`planned → running → won/lost`) →
rescore / kill / scale → re-optimized list (`README.md:6-11,63-64`).

Actual:

- **Does the board drive action? No.** Status moves are manual-only through the
  admin drawer (`public/app.js:219-260,331-376`); the worker explicitly never
  moves status (`worker/src/index.js:4-5`). Delegated state (top opp still
  `researching`/`planned` while real artifacts shipped elsewhere) matches the
  code: nothing syncs external repos, and nothing nudges stale `planned` rows.
- **Are metrics recorded? Barely.** `spent/result/post_mortem` are free text
  (`d1/schema.sql:55-61`); the API enforces nothing on `won/lost`
  (`functions/api/[[path]].js:209-228`); "post-mortem required" is a UI label
  only (`public/app.js:352`). No numeric spend/revenue, no experiment→score
  feedback.
- **Is the worker signal or noise? Backlog, for now.** 13 capped `UNREVIEWED`
  rows are proposals awaiting humans (`worker/src/index.js:247-260`). Triage is
  6 signals + ≤4 AI calls per run (`worker/src/index.js:14-16,192-194`), one
  brief per cron tick (`worker/src/index.js:283-285`), with no review-queue UI
  (§4 F2). It appends evidence faster than anyone can clear it.
- **Is scoring honest? Formula yes, ranking partly.** All 12 seed scores match
  the formula exactly (hand-recomputed; `d1/seed.sql:5-17`); `npm test` covers
  the formula (`worker/src/lib.test.js:8-12`). But the agent cap leaks above the
  human top pick (§4 F3), and scores never learn from experiment outcomes (§4 F6).

Verdict: the board ranks; it does not yet convert rank into experiments moved
and dollars measured.

## 4. Ranked findings (max 8)

**F1 — Top experiment stale; nothing moves the money path.**
The money step is a manual drawer edit behind the admin token; the agent is
forbidden from transitioning status, and no job flags stale `planned` rows.
So "1 planned experiment" can sit while the real 31-brand pack + proof site
ship elsewhere. Evidence: `worker/src/index.js:4-5`, `public/app.js:219-260`,
`public/app.js:331-376`, `d1/seed.sql:67-71`.

**F2 — 13 UNREVIEWED rows have no review queue.**
Agent proposals are marked only inside free-text `notes`; the ledger has status
chips but no `source=agent` / UNREVIEWED filter, and the drawer renders notes
as prose. Briefing covers one bare opportunity per cron tick, so vetting lags
insertions. Evidence: `worker/src/index.js:247-260`, `public/index.html:40-47`,
`public/app.js:63-84,183`, `worker/src/index.js:283-285`.

**F3 — Agent score cap does not guarantee mid-list.**
Cap is `value ≤ 7, confidence ≤ 5` with `fit` uncapped and `effort` down to 1,
so the capped max is `100·7·5·10/2 = 17500`, above the human top pick (16000).
The "enter mid-list until reviewed" comment over-promises. Evidence:
`worker/src/index.js:244-248`, `worker/src/lib.js:15-16`, `d1/seed.sql:6`.

**F4 — `supports` notes append keeps the oldest, drops the newest.**
`substr(notes || new, 1, 8000)` truncates from the right once full, so fresh
corroborating signals are silently discarded while stale text persists.
Evidence: `worker/src/index.js:271-275`.

**F5 — Experiment outcomes are unenforced free text.**
`won`/`lost` require no `result`/`post_mortem`; `spent/budget_cap` accept any
string; the API has no transition validation. Killed-with-learning (the stated
point of the board) is optional. Evidence: `d1/schema.sql:48-66`,
`functions/api/[[path]].js:209-228`, `public/app.js:352`.

**F6 — Score math is duplicated and deaf to experiments.**
Identical `scoreOf` lives in the worker and the API with no shared import and
no cross-boundary test; experiment results never feed back into
value/confidence/score — only manual edits rescore. Evidence:
`worker/src/lib.js:15-16`, `functions/api/[[path]].js:16-17,106-137`.

**F7 — Manual research path is fragile; auth is inconsistent.**
The dashboard trigger dead-ends when `RESEARCH_WORKER_URL` is unset; both cron
and manual runs share `waitUntil` despite the "cron gets longer" comment; the
API uses a constant-time token compare while the worker uses `!==`.
Evidence: `public/app.js:380-399`, `worker/src/index.js:7-11,174,333,395`,
`functions/api/[[path]].js:19-27`, `worker/src/index.js:343-345,388-391`.

**F8 — Docs/packaging drift: arXiv missing, seed re-run brittle.**
README advertises HN/Reddit/arXiv/GitHub but the worker scans HN/Reddit/GitHub
only. `deploy.sh` re-derives the row count via `python3 -c` with a `|| echo 0`
fallback; a parser failure would attempt a plain `INSERT` seed over a
non-empty table (no `OR IGNORE`). Evidence: `README.md:12-14`,
`worker/src/index.js:47-116`, `deploy/deploy.sh:34-42`, `d1/seed.sql:5`.

## 5. Design-practice gaps (max 6)

- **G1 — API untested.** Only `worker/src/lib.test.js` exists; the Functions
  router (auth, rescore, experiment transitions) has zero tests.
- **G2 — Orphan-hiding join; unenforced FKs.** `listExperiments` uses `INNER
  JOIN`, so an experiment whose opportunity is deleted vanishes instead of
  surfacing as orphaned (`functions/api/[[path]].js:181-187`); schema
  `REFERENCES` without `PRAGMA foreign_keys` is advisory in SQLite/D1
  (`d1/schema.sql:34,50,69-81`).
- **G3 — Brief numbers stored unvalidated.** Agent `numbers`/`sources` JSON is
  persisted without shape/URL checks; the "don't invent specifics" instruction
  (`worker/src/index.js:299`) has no compliance check.
- **G4 — No backlog SLOs.** No metric or alert for UNREVIEWED age/count, bare
  opportunities without briefs, stale `planned`/`running`, or hours since last
  `ok` run.
- **G5 — Secrets hygiene.** Account ID and D1 database ID are committed
  (`wrangler.toml:16`, `worker/wrangler.toml:14`,
  `deploy/public-surfaces.json:14-23`); admin token lives in `localStorage`
  (`public/app.js:9,282`) with no rotation/expiry notes.
- **G6 — Stale runbook.** No documented review flow (who vets UNREVIEWED, what
  flips `researching → testing`), and the seed/live counts (12 vs 40) are
  unexplained anywhere in-repo.

## 6. What not to change

- The scoring formula and the 12 honest seed values (`d1/seed.sql:5-17`).
- Capped-humility direction for agent proposals (fix the ceiling, not the idea;
  `worker/src/index.js:244-248`).
- Idempotent deploy (schema always, seed only when empty;
  `deploy/deploy.sh:30-42`).
- Triage hardening already earned live: NDJSON verdicts, underscore repair,
  per-signal validation, default-to-noise prompt, fetch/AI timeouts, batched
  D1 writes, heartbeats, stuck-run reaper
  (`worker/src/index.js:35-45,118-137,176-194,223-241`,
  `worker/src/lib.js:18-41`).
- Public-read / token-write split and the status vocabularies
  (`functions/api/[[path]].js:19-36`).
- Keeping killed ideas listed with post-mortems (`README.md:63-64`).
